# 工作流页面与 iframe 分享

工作流除了通过 API Key 调用，还可以生成独立页面或嵌入第三方系统。页面分享使用独立分享码，不需要向浏览器暴露 API Key。

## 创建分享

1. 在中台控制台打开 **工作流编排**。
2. 在已发布工作流的 **更多** 菜单中选择 **分享管理**。
3. 点击 **新建分享**，填写分享名称；标题、说明、主题和页面类型可以继承默认值。访问频率、允许嵌入的 Origin 和过期时间位于 **访问设置** 中。
4. 创建后复制独立链接或 iframe 代码。

分享可以随时停用。工作流被停用或取消发布后，对应分享也不能再启动执行。

**每分钟运行次数**只限制启动执行请求，失败或重新发送同样计数，不限制后台任务运行时长。页面加载、结果/事件查询、SSE 建立与取消请求共享独立读取防刷窗口（默认每条分享 120 次/分钟）；文件上传使用另一窗口（默认 20 次/分钟），并保留文件大小、类型与每日字节配额。三个窗口互不消耗额度，因此设置 2 次/分钟仍能完成两次运行的上传、订阅与查询。服务端可通过 `platform.workflow-share.read-rate-limit` 和 `platform.workflow-share.upload-rate-limit` 调整辅助请求限制；限流服务不可用时仍拒绝访问，不降级为无限制。API Key 的请求限流语义不受此修改影响。

分享停用、删除、过期或所属租户停用后，新请求会被拒绝；已建立的 SSE 观察连接也会复查当前授权并关闭，不继续沿用连接建立时的权限。事件发送前复查，静默连接按心跳周期复查（默认 15 秒），不是零延迟撤权。停用分享或关闭观察连接不会自动取消已经启动的后台任务；需要取消时，请在有权限的执行管理界面操作。

页面类型默认选择 **继承工作流默认（未配置时自动推荐）**，不会把创建时的推荐类型写成固定覆盖。解析顺序为：分享显式指定 > 工作流默认 > 自动推荐 > 表单；继承模式会跟随工作流默认类型的后续变更，显式指定的分享则保持原类型。

## 编辑与配置继承

桌面端在分享的 **更多 → 编辑分享** 中修改；手机端可直接点击卡片中的 **编辑**。保存不会重新生成分享码，已经分发的链接和 iframe 地址保持不变。

- 标题、说明留空，主题选择 **继承工作流主题**，表示移除当前分享的对应覆盖；**跟随系统** 则是明确使用 `auto`，不同于继承。
- 页面类型下方会显示实际采用的模板，以及它来自分享覆盖、工作流默认还是自动推荐。
- 清空过期时间可恢复永久有效。停用和过期不是同一状态；编辑内容不会自动启用已停用的分享。
- 对话模板可填写欢迎语及推荐问题（每行一个）；留空继承工作流配置。
- **模板高级配置** 接受 JSON 对象，并保留原有自定义字段。`{}` 表示不设置高级覆盖；标题、说明、主题和对话引导请使用对应表单，不要在 JSON 中重复设置。

图片工作台的配置示例（字段映射名称必须与实际输入 Schema 相符）：

```json
{
  "enabledModes": ["text_to_image", "image_to_image"],
  "sizeOptions": ["512x512", "1024x1024"],
  "maxGenerateCount": 2,
  "showDownload": false,
  "inputMapping": { "image": "sourceImage", "mode": "operation", "size": "imageSize", "count": "imageCount" },
  "outputMapping": { "images": "/image_result/output/imageUrl" }
}
```

这些配置控制页面交互，不会替工作流增加模型能力。

### 受控图片生成 / 编辑节点

在工作流中添加 **图片生成/编辑** 节点（`image:1.0`），绑定 **图片模型**（`IMAGE_MODEL`）资源；它与聊天模型资源分开，只能选择当前租户已启用相应图片能力的模型，不使用默认模型兜底，也不开放 Agent 的外部写工具。

- `GENERATE` 模式启用 `IMAGE_GENERATION`，输入 `prompt` 可映射表单的描述字段，使用图片模板展示结果。
- `EDIT` 模式启用 `IMAGE_EDIT`，目前只接受分享对话中**一个已授权图片附件**。将 `currentMessage` 映射到节点 `prompt`；后端会校验附件归属并转换图片，不接受任意源图网址、本机路径或表单上传的公共 `/profile/` 地址。
- 尺寸由管理员在节点配置中固定为 `1024x1024`、`1024x1536` 或 `1536x1024`；每次单图，不允许自动重试，也不提供节点模拟/预览执行。描述最多 8000 字符。
- 输出为 `images` 数组、`imageUrl` 和能力代码。图片/画廊/对话模板可显示图片；建议显式配置 `outputMapping.images`。对话结果不会显示原始节点 JSON 或调试详情。
- 继续经过模型运行时并发、请求频率与执行授权校验；云端免费额度及用完即停须由管理员在服务商配置，节点不能保证调用免费。图片数量不是 token，工作流 token/费用预算不能替代服务商的实际图片账单或余额控制。
- 模型请求超时上限 120 秒；超时、取消或连接中断并不保证服务商没有生成。执行若进入 `NEEDS_ATTENTION`，公开页提示管理员确认并阻止直接重发该结果，不自动恢复或重新调用模型。
- 当前返回服务商的临时 HTTPS 图片地址；不会自动转存公开目录，也不保证链接永久有效。长期保存需另行接入受控产物存储。

新节点的代码测试与页面回归不等于真实云端分享验收；部署后应使用单独 QA 流程、限额分享和合成图片实际验证。

### 工作流默认配置

分享列表右上角的 **默认配置** 可编辑工作流级标题、说明、主题、默认模板、对话引导及高级配置。保存确认后立即影响所有继承对应设置的分享，不改变单独覆盖的值，也不修改草稿、发布版本、分享码、限流或有效期。默认类型留空表示按已发布工作流自动推荐。

保存使用乐观并发检查；如果其他人修改了工作流，需重新加载配置并核对后保存，不会静默覆盖。编辑单个分享仍只修改该分享，不回写默认配置。

### 图片字段映射

图片及对比模板提供 **输入图片** 下拉框，选择已发布输入 Schema 中的顶层或嵌套对象图片 / URI / binary 字段。映射写入 `inputMapping.image`；例如 `/request/asset/photo`。上传会创建缺失的对象层级并保留同级参数，图片地址不再需要手工填写；同级参数在公开页以嵌套表单展示，完整 JSON 和必填校验仍使用原始输入契约。顶层名称保持兼容（含点号也视为原名称），嵌套可使用 JSON Pointer，或无歧义的点路径；Pointer 中 `/` 与 `~` 按 `~1` / `~0` 转义。最多支持 16 层，不接受原型字段、数组下标、动态键或未声明路径。

未指定输入图片时，优先使用唯一的 `contentMediaType: image/...` 字段，否则只在候选字段唯一时自动选择；多个候选会提示管理员配置，不默认选第一个。数组图片暂不支持单图上传/对比映射；可改用表单模板的高级 JSON 直接提交完整数组。图片模板的 `mode`、`size`、`count` 仍只支持顶层字段映射。

参数表单中的对象 / 数组 JSON 若有语法或类型错误，会禁用运行，也不能切换到高级 JSON 使用旧值；请先修正报错字段。嵌套字段同样生效，修改同级参数不会覆盖错误草稿。高级 JSON 中“生成示例”会明确重置草稿，但仍按完整契约校验，不能代替真实文件上传。

**图片输出** 从完整执行结果根对象读取：图片和画廊使用 `outputMapping.images`，对比使用 `outputMapping.resultImage`。支持 `image_result.output.imageUrl` 点路径及 `/image_result/output/imageUrl` JSON Pointer；数组元素可用 `/node/output/images/0`，字段名含 `/` 或 `~` 时用 Pointer 的 `~1` / `~0` 转义。映射目标应是图片 URL 或 URL 数组；不自动遍历目标内任意业务对象。

指定输出映射后不会回退到其他节点图片；无效结果显示配置提示，避免把原图或无关节点误作效果图。未配置时保留原有自动图片识别。只接受 HTTP(S)、`/profile/` 或受限图片 data URL，不支持脚本或本机文件地址。对比显式映射允许效果图与原图相同（例如无变化的处理结果）。

高级 JSON 中的 `inputMapping` / `outputMapping` 以整组覆盖默认映射，不是逐字段深合并；只改其中一项时请保留仍需使用的其他项。

### 管理接口的清空语义

以下接口使用中台登录认证及工作流读写权限，不使用公开分享访客身份：

- `GET /platform/workflow-shares/definition/{definitionId}`：读取已发布工作流的默认配置、推荐模板及输入 Schema。
- `PUT /platform/workflow-shares/definition/{definitionId}`：保存 `defaultPageType`、`sharePageConfigJson` 和读取到的 `expectedLockVersion`。缺少版本号或并发冲突会拒绝保存；显式空值清空默认配置。此接口不创建分享、不修改访问权限。
- `PUT /platform/workflow-shares`：按已有 `id` 更新分享，分享码和绑定工作流不变。

更新时省略 `pageType` / `expireTime` 会保留原值；显式传 `null` 会分别恢复模板继承 / 永久有效。只更新状态的请求不会清空这两个字段。页面配置按整份 JSON 替换，调用方需保留未修改的自定义字段；传入 `"{}"` 可移除全部页面配置覆盖。

## 独立页面

独立页面地址格式如下：

```text
https://your-polaris-host/app/{shareCode}
```

分享页面会根据输入 Schema 生成表单，并按配置加载表单、对话、报告、任务、查询、图片、对比或画廊模板。

## 报告导出

报告生成完成后，可使用 **复制报告**、**导出 PDF** 或 **导出原始数据**。

- PDF 在浏览器本地生成，不加载外部 CDN、不上传报告内容。首次导出会加载项目内的 PDF 依赖；生成时按钮显示忙碌状态，失败可重试。
- 亮色和暗色页面均导出适合打印的 A4 亮色版本；只包含报告正文，保留图表、中文和表格，添加页码，不包含运行参数和操作按钮。
- 长表格按页重复表头，结构化表格及普通结果表格都导出完整数据，不仅是当前可见分页。
- 原始数据继续导出 Markdown 或 JSON，适合编辑或进一步处理。
- PDF 正文采用图像渲染，不是可选择文本、可编辑或带无障碍标签的 PDF。复杂超长内容可能超过浏览器容量；报告副本超过 16000 CSS 像素或表格单行超过一页时会明确拒绝，请缩短内容或导出原始数据。

浏览器提示开始下载后，可在下载记录查看文件；这与工作流节点直接返回文件产物是不同能力。

## 对话附件

对话模板的输入框旁提供 **添加附件**。选择文件后等待上传及解析完成，再输入问题并发送；也可以只发送附件，让 AI 总结内容。发送前可预览或移除附件，发送后可点击附件卡片下载原文件。

- 每条消息最多 5 个附件，单文件不超过 10MB。
- 图片支持 PNG、JPEG、GIF、BMP；文档支持 PDF、DOCX、XLSX、XLS、TXT、Markdown、JSON、CSV、XML。
- 文档会解析为文本，并随对应用户消息传给工作流。扫描版 PDF 暂不支持 OCR；单文件只读取前 28000 字符，截断时会显示提示。
- 图片会转换为真正的模型图片输入，不是只传文件名或链接。工作流使用的模型必须开启 `VISION_INPUT`，不支持时会明确报错。
- 工作流需将 `currentMessage` 或 `messages` 映射到 LLM、AI 智能体或语义分类节点的输入，不能在中间步骤丢弃附件内容。
- 后续追问会携带本次对话的附件历史；历史最多 40 条消息、20 个附件、5 张图片，文档文本合计不超过 56000 字符。超过限制请开始新对话。

附件为短期私有文件，不生成公开静态地址，按租户、分享和访客会话隔离。附件引用有效期为 2 小时，使用时刷新；过期文件由定时任务清理。关闭或刷新页面不会恢复此前完整对话或附件，重要原文件请自行保存。

公开页仅在当前标签页保存最近一次执行 ID，最长 24 小时，不保存问题、附件凭据、结果或临时图片地址。刷新后点击“恢复上次执行”可只读查询原任务；仍需通过分享状态、有效期及访客归属校验，不会重新调用模型。未读取原执行前阻止新提交，避免重复生成。聊天恢复的结果不会作为完整历史送入下一轮，新对话可清除已恢复且不在运行的本页记录。禁用浏览器存储时仅能在当前页面恢复；关闭标签页后不保证记录仍在。服务商图片地址可能过期，恢复执行不等于永久保存图片。

恢复查询明确被拒绝（分享停用/过期、执行不存在或无权访问）时，页面停止等待并锁定直接重发；可选择“清除本页记录”。清除不是取消原任务，也不是确认云端没有生成，请勿据此直接重复生成。网络断开、限流或不确定执行结果仍应先恢复/联系管理员确认。分享校验失败的普通 JSON 响应可能使用 HTTP 200 搭配业务码 403/404，调用方必须同时检查业务码，不能只凭 HTTP 状态认定成功。

访客身份使用 HttpOnly、SameSite=Strict Cookie。浏览器需要允许同站 Cookie；跨站 iframe 的 Cookie 限制可能使附件上传不可用，此时请打开独立分享页面，不要通过关闭安全策略解决。

## iframe 嵌入

请使用分享管理中的 **复制嵌入** 获取代码。生成的地址会指向带动态安全策略的专用嵌入页：

```html
<iframe
  src="https://your-polaris-host/prod-api/platform/runtime/shares/{shareCode}/embed"
  style="width:100%;height:600px;border:0"
  loading="lazy">
</iframe>
```

不要直接把 `/app/{shareCode}` 放进跨域 iframe。直接跨域嵌入会被运行页拒绝。

## Origin 白名单

`iframe 来源` 每行填写一个完整 Origin，只包含协议、主机和可选端口：

```text
https://portal.example.com
https://admin.example.com:8443
```

只支持 HTTP(S)，不支持路径（包括末尾 `/`）、账号密码、查询参数、片段和通配符。端口须为 0–65535 范围内的整数；IPv6 主机须使用方括号，例如 `http://[::1]:3000`。协议、域名或端口任一不同都视为不同 Origin。未配置白名单时只允许 Polaris 自身同源页面嵌入。

服务端会在专用嵌入页上返回动态 `Content-Security-Policy: frame-ancestors ...`，浏览器据此阻止未授权站点加载页面。

从本地迁移到服务器时，分享链接和“复制嵌入”使用当前站点地址，但已保存的 Origin 白名单不会自动更改。若旧分享只允许 `http://localhost`，请按实际需要显式更新为正式嵌入站点的 Origin；不要为迁移而放宽为任意来源。通过域名打开的中台复制正式链接，避免从本地中台复制 localhost 链接用于线上。

## postMessage 事件

嵌入页会向已授权的父页面发送以下消息：

| `type` | 说明 | 附加字段 |
|:---|:---|:---|
| `polaris:ready` | 分享清单已加载 | - |
| `polaris:resize` | 内容高度变化 | `height` |
| `polaris:completed` | 工作流执行完成 | `executionId`、`status` |
| `polaris:error` | 页面加载失败 | `message` |

```javascript
window.addEventListener('message', event => {
  if (event.origin !== 'https://your-polaris-host') return
  if (event.data?.type === 'polaris:resize') {
    document.querySelector('#polaris-workflow').style.height = `${event.data.height}px`
  }
})
```

生产环境必须校验 `event.origin`，不要接收任意来源消息。

## 安全建议

- 分享码适合浏览器交互，不替代服务端 API Key。
- 只为确实需要嵌入的站点配置 Origin。
- 为临时活动设置过期时间，并按需停用分享。
- 不要把 API Key 写入前端代码、URL 或 iframe 参数。
## 受控图片节点的独立准入

图片节点具有真实计费副作用，仍标记为 WRITE，不能为接入生图而统一开启 `ai.workflow.write-nodes-enabled`。默认关闭的 `ai.workflow.image-nodes-enabled` 仅独立允许 image:1.0，并同时要求执行定义的租户 ID 在 `image-node-allowed-tenant-ids`、工作流编码在 `image-node-allowed-workflow-codes` 中；任一范围为空均拒绝。根执行及子工作流采用相同检查，范围外图片、HTTP 写请求及 Agent 写工具不会因图片开关获准。节点内仍检查显式租户模型、能力、附件归属及禁止重试。

启用图片节点时，须显式配置 `ai.workflow.image-nodes-enabled=true`、允许的租户 ID 和工作流编码。关闭图片开关可撤销图片启动准入，不影响已有结果只读查询。启用前应确认提供方配额和计费策略；该开关本身不能保证免费或替代云配额策略。
