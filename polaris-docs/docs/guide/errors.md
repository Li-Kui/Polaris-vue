# 错误处理与状态码

北辰 AI API 使用标准 HTTP 状态码来表示请求的成功或失败。

## 状态码对照表

| 状态码 | 说明 | 应对措施 |
|:---|:---|:---|
| `200 OK` | 请求成功 | 正常处理业务响应 |
| `400 Bad Request` | 请求参数格式错误或缺少必填字段 | 检查请求体 JSON 是否合规 |
| `401 Unauthorized` | 身份验证失败（API Key 缺失或无效） | 检查 X-API-Key 请求头 |
| `403 Forbidden` | 权限受限或 Key 已停用/过期 | 前往控制台检查 Key 状态 |
| `429 Too Many Requests` | 超出并发/速率限制，或租户配额耗尽 | 联系租户管理员充值配额，或放缓请求频率 |
| `500 Internal Error` | 中台后端内部处理异常 | 检查模型配置及后端日志 |
